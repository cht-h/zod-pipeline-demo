**Репозиторий библиотеки:** https://github.com/colinhacks/zod

## Описание
Демонстрационный проект показывает внутреннее устройство механизма валидации Zod (конвейер `parse` + `checks`). Скрипт демонстрирует, как схема собирает проверки, как работает `safeParse`, как ошибки накапливаются в `payload.issues` и как срабатывает JIT-оптимизация.

## Инструкция запуска
1. Установите зависимости: `npm install`
2. Запустите скрипт: `node demo.js`
